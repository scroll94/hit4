# Marsel — портфолио

Сайт-портфолио веб-разработчика: одна длинная 3D-сцена, по которой камера летит вместе с прокруткой.

**Открыть сайт:** https://scroll94.github.io/hit4/

## Что внутри

- Загрузка, затем комната-сетка с монограммой из точек.
- При прокрутке монограмма рассыпается на частицы, камера опускается к работам.
- Работы под «линзой»: обложки рисуются кодом.
- Раздел «Обо мне»: полёт по тоннелю.
- Красный финал с контактами.

Палитра: Obsidian Black `#111217`, Ice Grey `#DFE5EB`, Racing Red `#EF233C`.

## Как устроен репозиторий

- В корне лежит готовый собранный сайт, его показывает GitHub Pages.
- В папке [`source`](source) лежат исходники: Vite, TypeScript, Three.js, GSAP, Lenis.
- Весь текст сайта находится в одном файле: [`source/src/content.ts`](source/src/content.ts).

## Запуск у себя

```bash
cd source
npm install
npm run dev
```

Собрать сайт заново: `npm run build` в папке `source`, затем содержимое `dist` положить в корень репозитория.
